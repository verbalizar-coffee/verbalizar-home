# CUP COMPASS ── 公開手順

## このフォルダの中身

HTMLファイル4枚だけです。CSSもJavaScriptも画像も、**すべて各HTMLの中に埋め込んであります**。
1枚だけダブルクリックしても、そのページ単体で完全に表示されます。

| ファイル | 中身 |
|---|---|
| `index.html` | 表紙 |
| `cup-compass-daily.html` | 今日の一杯を直す（コツ・抽出シアター・ニュース） |
| `soil-to-cup.html` | 土から一杯まで（6ステップ・知の地図・ライブラリ） |
| `blend-lab.html` | 配合を設計する |

4枚は互いにリンクしているので、ページ間を移動したい場合は**同じフォルダに4枚とも置いてください**。

## GitHub Pages で公開する

### 1. リポジトリを作る
GitHub で新しいリポジトリを作成します（Public）。名前は何でも構いません。

### 2. 4つのHTMLをアップロードする
リポジトリのトップ画面で **Add file → Upload files**。
4枚をドラッグして **Commit changes**。

> **重要：フォルダを作らず、リポジトリの一番上の階層に置いてください。**
> `index.html` がトップにないと、公開URLを開いても表紙が出ません。

### 3. Pages を有効にする
**Settings → Pages** を開き、

- **Source**: `Deploy from a branch`
- **Branch**: `main` / `/ (root)`

**Save** を押します。

### 4. 1〜2分待つ
`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
URLは Settings → Pages の上部に表示されます。

## よくあるつまずき

**表紙が出ず、ファイル一覧が表示される**
`index.html` がリポジトリのトップにありません。フォルダの中に入れた場合は、そのフォルダ名をURLの末尾に足すか、トップへ移動してください。

**リンクを押すと 404 になる**
4枚のうち一部しかアップロードしていません。ファイル名の綴りも確認してください（`cup-compass-daily.html` など、大文字小文字も区別されます）。

**文字が明朝にならない**
Google Fonts をネットから読み込んでいます。オフラインでは端末の標準明朝で表示されます（レイアウトは崩れません）。

**更新したのに反映されない**
GitHub Pages の反映には最大数分かかります。ブラウザの強制再読み込み（Ctrl/Cmd + Shift + R）も試してください。

## 設定を変える

各HTMLの後半にある `CONFIG` を書き換えます。

```js
const CONFIG={
 gasUrl:"",                    // GASウェブアプリのURL（投稿をシートへ飛ばす）
 lastUpdated:"2026-08-27",     // 表紙フッターの最終更新日
 affiliate:{ amazonTag:"" }    // Amazonアソシエイト等のID
};
```

色と書体は、各HTMLの `<style>` 冒頭にある `:root` にまとまっています。

```css
--ink:#16262A;      /* 墨 */
--indigo:#16495D;   /* 藍 */
--cherry:#A9302A;   /* 実（CTA） */
--leaf:#4E6B4A;     /* 葉 */
--sun:#C98A2E;      /* 陽 */
```

4枚とも同じ値を書き換えれば、サイト全体の見た目が一度に変わります。
